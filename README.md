# menu.ezhdanov.com

Карманный помощник для португальских меню: работает офлайн и ставится на телефон как приложение.

- **Словарь**: все продукты, блюда и кулинарные термины по алфавиту, PT → RU (+ EN), с озвучкой. Слова из чата «EN ⇄ PT Translator» помечены «из чата».
- **Блюда**: поиск по всем сфотканным меню на PT, RU или EN. Опечатки и отсутствие диакритики не мешают. Плюс перевод любого названия по словам, даже если блюда ещё нет в базе.
- **Карточки**: PT → RU и RU → PT (с вводом ответа), набор на выбор: все слова, категория, блюда конкретного ресторана. Повторение по коробкам Лейтнера.
- **Меню**: новые меню добавляются по фото. Распознаёт и переводит Claude (нужен свой API-ключ). Без интернета фото встают в очередь. Синхронизация с GitHub делает новые меню видимыми на всех устройствах.

## Устройство

Статический сайт без сборки (GitHub Pages): `index.html`, `css/`, `js/` (ES-модули), `sw.js` (офлайн-кеш).

| Файл | Что внутри |
|---|---|
| `data/words.json` | словарь (генерируется) |
| `data/chat_menus.json` | меню из чата (генерируется) |
| `data/menus.json` | меню, добавленные из приложения (пишет синхронизация с GitHub) |
| `photos/` | фото меню, добавленных из приложения |
| `tools/base_words.txt` | базовая лексика меню |
| `tools/source/` | выгрузка из чата и русские переводы к ней |
| `vendor/claude.js` | Anthropic SDK для браузера, сборка из `tools/claude-bundle/` |

Пересобрать данные после правок в `tools/`:

```bash
python3 tools/build_data.py
```

Пересобрать `vendor/claude.js`:

```bash
cd tools/claude-bundle && npm install && npm run build
```

После изменения файлов приложения увеличь `VERSION` в `sw.js`, чтобы телефоны быстрее подтянули обновление.
